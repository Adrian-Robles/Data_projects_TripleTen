# Superstore Return Analysis

## Project Overview

This project analyzes customer return behavior using Tableau to identify trends in returned products, profitability, customer behavior, and geographic patterns.

## Business Problem

High product return rates can negatively impact revenue and customer satisfaction. This analysis helps identify where returns are occurring most frequently and which products or locations contribute the most to return losses.

## Tools Used

- Tableau
- Excel
- Data Visualization

## Key Insights

- Identified product categories with the highest return rates.
- Compared profitability against returned products.
- Analyzed customer return behavior.
- Visualized geographic return trends.
- Created an interactive dashboard to support business decision-making.
